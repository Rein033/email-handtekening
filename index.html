Met vriendelijke groet,

Zo zet je hem in je mailprogramma

Outlook (nieuw / web): Instellingen → Account → Handtekeningen → Nieuwe handtekening → plakken (Ctrl+V).

Outlook (klassiek): Bestand → Opties → E-mail → Handtekeningen → Nieuw → plakken.

Gmail: Instellingen (tandwiel) → Alle instellingen bekijken → Handtekening → Nieuwe maken → plakken → onderaan Wijzigingen opslaan.

Apple Mail: Instellingen → Handtekeningen → + → plakken. Zet "Gebruik altijd mijn standaardlettertype" uit.

Foto en logo moeten een openbare link zijn (bijv. van je website of LinkedIn), anders ziet de ontvanger ze niet.
